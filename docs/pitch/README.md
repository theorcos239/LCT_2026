# Презентация 239.Hack

- [Короткая версия для пятиминутного выступления](239.Hack_DXA_QC_питч.pdf) — первые восемь слайдов показываются; затем идут обязательные слайды 7–11 шаблона.
- [Короткая версия для редактирования](239.Hack_DXA_QC_питч.pptx).
- [Полная версия](239.Hack_DXA_QC_полная_версия.pdf) и [её исходник](239.Hack_DXA_QC_полная_версия.pptx) — для загрузки материалов конкурса.
- [Подробная версия с интервалами](DXA_details_public.pdf) и [PPTX](DXA_details_public.pptx) — публичная копия, в которой скриншоты со снимками заменены схемами. [Метод расчёта интервалов](DXA_details_CI.md).

В этих файлах примеры интерфейса и нарушений нарисованы схемами. Изображений пациентов и фрагментов снимков нет. Числа на слайдах относятся к указанным там проверкам; общая оценка текущей сборки после изменения правила отступов ещё требует повторного прогона.

Клинические снимки, разметка и построчные предсказания хранятся отдельно от публичного репозитория. Локальный `DXA_details.pptx` содержит клинические скриншоты и исключён из Git. Для отправки используйте только файлы с суффиксом `_public` либо другие проверенные презентации из этой папки.
