Розовые полосы показывают приближённые 95% интервалы **для новых чисел, указанных на слайде**. Сиреневые полосы перенесены из прежней версии презентации Михаила и не пересчитаны. Индивидуальные предсказания этой версии не сохранены рядом с PPTX; поэтому точный бутстрэп по исследованиям не воспроизводится. ## Сиреневая серия «до»

Серия «до» взята из поля `honest_oof` файла `runs/eval_baseline/metrics.json`, где каждый кадр проверялся с порогом, выбранным без этого кадра. Интервалы в нём получены бутстрэпом по исследованиям.

| Критерий | F1, 95% | ROC-AUC, 95% |
|---|---:|---:|
| Укладка | **0,32 [0,08–0,55]** | **0,82 [0,58–0,95]** |
| Наклон оси | **0,25 [0,00–0,48]** | **0,82 [0,72–0,92]** |

Ранее для синей серии укладки по ошибке было взято `per_violation.f1 = 0,91` из того же файла — оценка на данных, где подбирался порог. Это не показатель «до» на проверочных снимках. На слайде 9 ошибка исправлена.
