# Проверка решения: с чего начать

Для кого: эксперт, который проверяет решение на закрытом наборе без участия
команды (ТЗ 7.2). Здесь — как получить отчёт за пять минут и где в
репозитории закрыт каждый пункт ТЗ.

## Отчёт на закрытом наборе

Linux или любая система с Docker. Веса моделей лежат в репозитории, сеть
после сборки не нужна:

```bash
git clone https://github.com/theorcos239/LCT_2026 && cd LCT_2026
./build.sh                                     # образ dxa-qc:1.0.0, 1–3 минуты
./run.sh batch /путь/к/закрытому_набору        # отчёт в ./out
FMT=csv ./run.sh batch /путь/к/закрытому_набору  # то же в csv
```

В `./out` появятся:

| файл | что внутри |
|---|---|
| `report.xlsx` (`.csv`) | строка на уникальный снимок; первые восемь колонок — ровно ТЗ 2.5, в том же порядке |
| `details.json` | все измерения: углы, миллиметры, вероятности, флаги |
| `overlays.zip` | дополнительная серия с визуализацией нарушений (ТЗ 2.6) |
| `sr.zip` | DICOM SR с текстовым заключением на каждый снимок (ТЗ 2.6) |

Для ROC-AUC бинарного класса — колонка `quality_probability`, по типам
нарушений — `p_spine_position`, `p_spine_axis`, `p_spine_artifacts`,
`p_hip_rotation`, `p_hip_roi`. Коды нарушений в `violation_type` — через `;`.

Скорость: 1.6 с на исследование на одном ядре CPU (максимум 2.3 с при
лимите ТЗ в 3 минуты), 100 исследований — около 2.5 минут. GPU не нужен.
Папка с данными монтируется только на чтение.

**Без Docker.** Windows — установщик настольного приложения
([DESKTOP.md](DESKTOP.md)), затем `dxa-qc-cli batch папка --out report.xlsx`.
Любая ОС с Python 3.11 — `pip install -r requirements.lock` и
`python -m service.cli папка --out report.xlsx`. Все три пути дают один и тот
же отчёт: контейнер, установленное приложение и локальный Python сверены на
всех 252 снимках обучающего набора — вердикты, флаги и вероятности совпадают
побитово.

**Правило для отступов ROI.** По умолчанию отступы бедра судятся по длине поля
сканирования — так оценивает эксперт в `разметка.xlsx` (F1 0.71 против 0.35 у
буквального прочтения рисунка 6). Если эталон закрытого набора размечен строго
по рисунку 6 ТЗ, включите режим ТЗ: `ROI_RULE=margins ./run.sh batch ...`
(то же для `./run.sh` — веб-интерфейс и API; у CLI — `--roi-rule margins`).
Отступы по рисунку 6 в `details.json` есть при любом правиле. Разбор — README,
раздел «Критерии и метрики».

## Тесты

Нужен обучающий набор рядом с кодом (`НД_для_обучения/`, в git не хранится):

```bash
python -m service.test_service        # 64 проверки: формат, устойчивость, дедупликация, детерминизм, API, сеть, SR
python -m bot.test_bot                # 27 проверок Telegram-бота без сети
python -m region_clf.test_region_clf  # 499 файлов + симметрия lh/rh
python -m hip_roi.test_hip_roi        # фантом + реальные кадры
python -m service.evaluate            # метрики с ДИ, честная out-of-fold оценка
```
