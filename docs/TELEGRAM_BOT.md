# Telegram-бот

Для кого: тот, кто хочет показать сервис или проверить снимок с телефона, и
тот, кто запускает бота на своём компьютере. Инструкция для пользователя —
[Инструкция_Telegram-бот.pdf](Инструкция_Telegram-бот.pdf).

Бот команды — **[@LCT_bone_density_research_bot](https://t.me/LCT_bone_density_research_bot)**.
Он отвечает, пока запущен на ноутбуке команды. Свой экземпляр поднимается за
минуту на любом компьютере с интернетом (раздел «Запуск»).

**Зачем он нужен.** Бот — приятный бонус, а не обязательная часть проекта:
решение по ТЗ — это контейнер, веб-интерфейс и настольное приложение, и они
работают без бота. Бот показывает, что конвейер легко встроить в любой другой
интерфейс: тот же анализ, что в контейнере и приложении, отвечает
в чате, с телефона, без установки чего-либо. Это заготовка для дальнейшей
доработки и интеграции в другие сервисы — корпоративный мессенджер
медорганизации, МИС, систему уведомлений: клиент Bot API занимает один файл, а
вся логика ответов отделена от Telegram (раздел «Как устроен»).

> **Только обезличенные данные.** Файлы, отправленные боту, проходят через
> серверы Telegram. ТЗ (п. 3.2) требует не передавать медицинские изображения
> во внешние системы, поэтому бот — необязательный демонстрационный интерфейс, а не часть
> основного решения, и для снимков реальных пациентов не предназначен.
> Контейнер, настольное приложение и веб-интерфейс работают без интернета. Бот
> по умолчанию не запускается.

## Как пользоваться

1. Откройте бота и нажмите «Старт».
2. Пришлите **файлом** (скрепка → «Файл»): один или несколько DICOM-снимков
   (они считаются одним исследованием) или zip с исследованиями — вложенность
   папок любая, дубликаты снимков схлопываются. До 20 МБ за раз: больше бот
   скачать не может, это ограничение Telegram.
3. Через несколько секунд придут:
   - **сводка** — по каждому снимку область и вердикт; для нарушений —
     объяснение в миллиметрах и градусах («поле сканирования 12.5 см короче
     12.9 см», «ось отклонена на 7.1°»), флаги «проверьте глазами»;
   - **снимки с разметкой** альбомом: найденные ориентиры, пороги ТЗ,
     тепловая карта нейросети. До 10 снимков — все, больше — только с
     нарушением;
   - **report.xlsx** — таблица отчёта: восемь колонок ТЗ 2.5, дальше
     вероятности, флаги, описания.
4. Кнопки под сводкой: **DICOM SR** (текстовое заключение по каждому снимку),
   **измерения .json**, **все снимки с разметкой .zip**. Результаты хранятся
   3 часа, потом удаляются.

Команды: `/start` — как пользоваться, `/demo` — пример на семи
демо-исследованиях (если демо-архив есть на компьютере, где запущен бот),
`/about` — что проверяется и метрики, `/help` — форматы и ограничения.

Фото и скриншоты не подходят: Telegram их сжимает, и DICOM-данных в них нет —
бот попросит прислать файл.

## Запуск

Бот работает long polling'ом: сам спрашивает Telegram о новых сообщениях,
поэтому белый IP, открытые порты и HTTPS не нужны — хватает ноутбука с
интернетом. Токен бота выдаёт [@BotFather](https://t.me/BotFather) (`/newbot`).

**Токен в репозиторий не кладётся.** Он живёт в файле `.env` (в
`.gitignore`), в переменной окружения или в папке настроек пользователя:

```bash
cp .env.example .env        # и впишите DXA_QC_TG_TOKEN=...
```

### Из репозитория (Windows, Linux, macOS)

```bash
pip install -r requirements.lock
python -m bot --check       # проверить токен
python -m bot               # запустить; остановить — Ctrl+C
```

На Windows — с перезапуском при сбое и, по желанию, автозапуском при входе
в систему (права администратора не нужны):

```powershell
powershell -ExecutionPolicy Bypass -File bot\run_bot.ps1              # в этом окне
powershell -ExecutionPolicy Bypass -File bot\run_bot.ps1 -Autostart   # в фоне и при каждом входе
powershell -ExecutionPolicy Bypass -File bot\run_bot.ps1 -RemoveAutostart
```

Журнал — `%LOCALAPPDATA%\DXA-QC\logs\bot.log`.

### В контейнере

Бот входит в образ сервиса:

```bash
./run.sh bot                                   # токен из .env рядом со скриптом
docker run -d --restart unless-stopped --name dxa-qc-bot \
       --env-file .env dxa-qc:1.0.0 python -m bot   # постоянно, с перезапуском
```

### Из установленного приложения

Ярлык «Telegram-бот» в меню «Пуск» (папка «Контроль качества DXA») или
`dxa-qc-cli bot`. При первом запуске бот спросит токен, проверит его и
сохранит в `%APPDATA%\DXA-QC\bot.env`.

## Настройки

| переменная | по умолчанию | смысл |
|---|---|---|
| `DXA_QC_TG_TOKEN` | — | токен бота, обязателен |
| `DXA_QC_TG_ALLOWED` | пусто — всем | кому можно пользоваться: id или `@username` через запятую |
| `DXA_QC_DEMO` | `demo.zip` рядом с ботом | архив для `/demo`; в репозиторий не входит, потому что содержит снимки |
| `DXA_QC_ROI_RULE` | `scan_length` | отступы ROI: как эксперт (`scan_length`) или строго по рисунку 6 ТЗ (`margins`) |
| `DXA_QC_CNN` | `1` | `0` — без нейросети, только геометрия |

Переменные окружения важнее файла `.env`.

## Как устроен

`bot/telegram.py` — клиент Bot API на стандартной библиотеке Python: бот не
добавляет ни одной зависимости и живёт в том же образе и установщике, что
сервис. `bot/app.py` — очередь заданий (снимки считаются по одному заданию за
раз, модели загружены один раз), сборка альбомов из нескольких файлов,
ответы. Анализ — тот же конвейер `service.pipeline`, что у CLI, API и
настольного приложения, поэтому вердикты совпадают с ними побитово.

Файлы пишутся во временную папку и удаляются сразу после обработки; готовые
отчёты для кнопок — через 3 часа. Токен не попадает ни в журнал, ни в тексты
ошибок.

Тесты без сети (Telegram подменён заглушкой, конвейер настоящий):

```bash
python -m bot.test_bot
```

## Если что-то не так

| симптом | причина и что делать |
|---|---|
| бот молчит | не запущен: проверьте окно или журнал; `python -m bot --check` |
| в журнале «уже слушает другой экземпляр» | тот же токен запущен в другом месте — остановите лишний экземпляр |
| «Файл весит N МБ» | больше 20 МБ: разделите архив или используйте настольное приложение |
| «Демо-архива на этом компьютере нет» | положите `demo.zip` рядом с ботом или задайте путь к нему в `DXA_QC_DEMO` |
| «Доступ к этому боту ограничен» | задан `DXA_QC_TG_ALLOWED`, и вас в нём нет |
