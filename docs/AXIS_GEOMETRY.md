# Наклон кадра при искривлённом позвоночнике

## Что измеряется

Искомый угол `θT` — поворот анатомической конструкции относительно вертикали
кадра. Сколиотическая дуга не является нарушением качества, но смещает центры
позвонков и поэтому искажает прямую МНК через L1–L4.

Координаты переводятся в миллиметры; `y` направлен вниз. Положительный угол
означает, что низ позвоночника уходит вправо:

```
c_k = R(θT) [0, y_k]ᵀ + δ_k n + ε_k
α_k = θT + γ_k + η_k
```

`δ_k` — боковое смещение центра на дуге, `γ_k` — локальный наклон тела,
`ε_k, η_k` — ошибки точек.

## Ошибка линии центров

Для нормированной координаты `t` вдоль хорды L1–L4 и шага `L`:

```
θC = atan(Σ w_k(y_k-ȳ)(x_k-x̄) / Σ w_k(y_k-ȳ)²)
ΔθC ≈ Σ w_k(t_k-t̄)δ_k / (L Σ w_k(t_k-t̄)²)
```

Для C-дуги `δ(t) = -κL²(t-ta)²/2`:

```
ΔθC ≈ atan(κL(ta-t̄)) ≈ κL(ta-t̄)  (малые углы)
```

МНК измеряет касательную дуги в середине окна, а не чистый поворот кадра.
При вершине в середине окна смещение равно нулю, при вершине у края растёт.
Для S-дуги `δ(t)=c3 t³`:

```
ΔθC ≈ c3 Σt⁴ / (L Σt²)
```

Поворот параболы на малый угол снова даёт параболу. Поэтому по четырём
центрам нельзя однозначно разделить наклон и дугу: нужен независимый источник.

## Замыкательные пластинки

Для пары краёв тела `d=eL-eR`, приведённой к `dx>0`:

```
α_k = -atan2(dy, dx)
θE = Σv_k α_k / Σv_k
σ_α,k ≈ √2 σpt / W_k
```

`W_k=|eL-eR|`. Чем шире тело и точнее края, тем надёжнее угол. Ошибка дуги
этого источника равна среднему локальному повороту тел `mean(γ_k)`, а не
линейному смещению центров.

## Дескрипторы дуги и дисперсии

В системе хорды аппроксимируется `x(t)=q0+q1t+q2t²`. Сама хорда поглощает
линейную часть дуги, поэтому положение вершины по центрам отдельно
неидентифицируемо. Его эффективное плечо оценивается независимыми пластинками:

```
κL = 2q2/L
|ta-t̄| ≈ |tan(θC-θE)| / |κL|
σC² = σC0² + (bC |κL| max(|ta-t̄|,τ))² + (br rms(r)/L)²
σE² = σE0²/nE + (bE std(α))²/nE
σK² = σK0² + (bK curvature_mm/L)²
```

Коэффициенты калибруются только на обучающих фолдах.

## Итоговый угол

Центры (`θC`), пластинки (`θE`) и контур (`θK`) объединяются по обратным
дисперсиям:

```
θ̂ = Σ θi/σi² / Σ 1/σi²
σ̂ = (Σ 1/σi²)^(-1/2)
Q = Σ(θi-θ̂)²/σi²
```

При `Q>9.21` (χ², 2 степени свободы, p=0.01) источники несовместимы.
Для двух источников предел χ² с одной степенью свободы — 6.63.

Решение при нормативном пороге 5°:

- `|θ̂| + kσ̂ < 5°` — пригоден;
- `|θ̂| - kσ̂ > 5°` — непригоден по `spine_axis`;
- иначе — пограничное измерение, ручная проверка.

Порог не меняется из-за сколиоза. Меняются угол и его неопределённость.

## Проверка гипотезы

`python tools/simulate_axis_bias.py` строит 2457 комбинаций технического
поворота, C-дуги, положения вершины и трёх моделей наклона тел. Формула
смещения линии центров имеет MAE 0.087°, но объединённый угол в худшей ячейке
проигрывает лучшему отдельному источнику на 11.88° при пределе 0.3°.
Следовательно, формула смещения работает как диагностика, а текущий метод
слияния **не прошёл синтетический гейт**. OOF по всем 73 снимкам также не
прошёл G2: F1 0.267, FN 6, 27.4% решений `undetermined`.
Параметры шума подбираются только по обучающим
исследованиям, однако большой интервал bootstrap F1 и отсутствие проверенной
сквозной метрики не позволяют включать новый вердикт.
