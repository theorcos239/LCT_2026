# Настольное приложение для Windows

Для кого: врач или лаборант, которому нужен сервис на своём компьютере без
Docker, и тот, кто собирает установщик. Пошаговая инструкция —
[Инструкция_приложение.pdf](Инструкция_приложение.pdf).

Приложение — тот же сервис, что в контейнере, упакованный в один установщик.
Внутри тот же конвейер, те же веса и те же версии пакетов (`requirements.lock`),
поэтому отчёт совпадает с контейнером **побитово**: это проверено на всех 252
снимках обучающего набора — вердикты, флаги и вероятности одинаковые.

## Установка

1. Откройте папку `установщик` — она лежит рядом с папкой проекта. В ней один
   файл: установщик `DXA-QC-Setup-1.0.0.exe` (около 290 МБ). Запустите его.
   В репозитории готового установщика нет; собрать его самому — раздел
   «Сборка установщика». Права администратора не нужны:
   приложение ставится в `%LOCALAPPDATA%\Programs\DXA-QC`. Для всех
   пользователей компьютера — выберите это в первом окне мастера.
2. Установщик не подписан сертификатом, поэтому Windows может показать
   SmartScreen «Система Windows защитила ваш компьютер». Нажмите
   «Подробнее» → «Выполнить в любом случае».
3. Отметьте по желанию: ярлык на рабочем столе, `dxa-qc-cli` в PATH (чтобы
   пакетная обработка работала из любой консоли).

## Требования к компьютеру

Приложению хватает обычного офисного компьютера или ноутбука:

| | требование |
|---|---|
| система | Windows 10 или 11, 64 бита; права администратора не нужны |
| процессор | любой 64-разрядный (x86-64) с двумя ядрами и больше. На современном ноутбуке одно исследование обрабатывается за 1.6 с; на более слабом процессоре — дольше, но с большим запасом до лимита ТЗ в три минуты |
| оперативная память | 4 ГБ; сама программа занимает до 0.8 ГБ (измерено на демонстрационном архиве) |
| диск | 1 ГБ свободного места: программа занимает около 520 МБ, установщик — около 290 МБ |
| видеокарта | не нужна |
| интернет | не нужен ни для установки, ни для работы |
| окно приложения | WebView2 Runtime (встроенный в Windows компонент браузера Edge) — есть в Windows 11 и обновлённой Windows 10; без него интерфейс откроется в браузере |

Если WebView2 Runtime не установлен, установщик предупредит об этом.

Нужна другая версия — соберите установщик сами (раздел «Сборка» ниже); там
же собирается переносной zip: распакуйте и запустите `DXA-QC.exe`, установка
не нужна.

## Работа без интернета и обновление

Приложение работает полностью на этом компьютере. Сервер поднимается внутри
программы на адресе `127.0.0.1` (это адрес самого компьютера) и извне не
виден; все модели и веса лежат в папке программы и читаются с диска. Ни одна
страница приложения не обращается в интернет: даже страница описания API
(`/docs`) отдаётся из локальной копии Swagger UI. Телеметрии нет — сбор
диагностики в onnxruntime (библиотеке, которая исполняет нейросеть) выключен
в коде; проверки обновлений тоже нет. Единственный интерфейс, которому нужен
интернет, — Telegram-бот: это необязательный бонус, и он запускается отдельно.

Обновление — новая версия ставится тем же установщиком поверх старой:
закройте приложение и запустите `DXA-QC-Setup-<версия>.exe`, удалять ничего
не нужно. Установщик узнаёт прежнюю копию (у всех версий один AppId) и
заменяет файлы программы; журналы, отметки специалиста и токен бота лежат
отдельно, в `%LOCALAPPDATA%\DXA-QC` и `%APPDATA%\DXA-QC`, и сохраняются.
Какая версия установлена — `dxa-qc-cli version` или «Параметры» →
«Приложения». Автоматическая проверка обновлений — задел на развитие.

## Что появляется в меню «Пуск»

Папка «Контроль качества DXA»:

| ярлык | что делает |
|---|---|
| **Контроль качества DXA** | окно приложения: сервис поднимается внутри на `127.0.0.1`, наружу не виден |
| Командная строка (пакетная обработка) | консоль в папке программы с подсказкой по командам |
| Веб-сервер для локальной сети | тот же интерфейс в браузере для коллег в вашей сети, порт 8000. Только для доверенной сети клиники — см. «Пакетная обработка из консоли» |
| Telegram-бот | необязательный бонус — демонстрация альтернативного интерфейса: тот же анализ отвечает в чате, с телефона. Это заготовка для доработки и интеграции в другие сервисы; для реальных данных пациентов бот не предназначен — файлы проходят через серверы Telegram, поэтому только обезличенные снимки. При первом запуске спросит токен — см. [TELEGRAM_BOT.md](TELEGRAM_BOT.md) |
| Инструкция — приложение, Инструкция — Telegram-бот | инструкции пользователя в PDF (попадают в установщик, если при сборке лежали в `docs/`) |
| ПРОЧТИТЕ | краткая справка |
| Деинсталлировать Контроль качества DXA | удаление программы; перед ним выгрузите отметки специалиста — см. «Где что лежит» |

## Работа в окне

Окно — это веб-интерфейс сервиса ([USER_GUIDE.md](USER_GUIDE.md), раздел
«Веб-интерфейс»): перетащите папку с исследованиями, zip или DICOM-файлы,
листайте снимки с разметкой и нормами, отмечайте согласие с вердиктом,
скачивайте таблицу отчёта, измерения, визуализацию и DICOM SR. Файлы
сохраняются в папку «Загрузки».

Первый запуск после установки занимает до минуты: Windows проверяет новые
файлы антивирусом. Дальше окно открывается за несколько секунд.

Результаты хранятся 24 часа: после перезапуска они видны на стартовом экране
в списке «Недавние задания». Отметки специалиста хранятся, пока установлено
приложение.

Если запустить приложение второй раз, новый сервис не поднимается — второе
окно подключается к уже работающему. Сервис останавливается вместе с первым
окном; второе окно тогда покажет «сервис недоступен».

## Пакетная обработка из консоли

```bat
dxa-qc-cli batch D:\исследования --out D:\результат\report.xlsx
dxa-qc-cli batch архив.zip --out report.csv --overlays overlays.zip --sr sr.zip --details details.json
dxa-qc-cli serve                     :: веб-интерфейс и API для локальной сети, порт 8000
dxa-qc-cli serve --host 127.0.0.1    :: только для этого компьютера
dxa-qc-cli bot                       :: Telegram-бот
dxa-qc-cli version
```

Ключи `batch` — те же, что у `python -m service.cli` (README, «Входные и
выходные данные»): `--roi-rule margins` — вердикт по отступам области
интереса дословно по рисунку 6 ТЗ, `--no-cnn` — без нейросети.

Команда `serve` открывает интерфейс всем компьютерам вашей сети без пароля:
любой, кто знает адрес, увидит список заданий и сможет скачать отчёты.
Поэтому она предназначена только для доверенной локальной сети клиники
(закрытого контура). Для одного компьютера — `--host 127.0.0.1`; окно
приложения и так работает только на этом адресе.

## Где что лежит

| что | где |
|---|---|
| программа | `%LOCALAPPDATA%\Programs\DXA-QC` |
| журнал окна | `%LOCALAPPDATA%\DXA-QC\logs\desktop.log` |
| временные файлы заданий | `%TEMP%\dxa_qc_jobs` (удаляются через 24 ч) |
| токен Telegram-бота | `%APPDATA%\DXA-QC\bot.env` |

Удаление — «Параметры» → «Приложения» или ярлык «Деинсталлировать». Удаляются
программа, журналы, кэш окна (а вместе с ним — отметки специалиста
«согласен / не согласен») и сохранённый токен бота. Если отметки нужны,
сначала выгрузите их кнопкой «Мои отметки .csv». Переход на новую версию —
не удаление: новый установщик ставится поверх старого, и всё это
сохраняется (раздел «Работа без интернета и обновление»).

## Как устроено

```
DXA-QC.exe (окно)                        dxa-qc-cli.exe (консоль)
   │  pywebview → WebView2                  batch → service.cli
   │                                        serve → uvicorn service.api
   └─ uvicorn service.api  127.0.0.1:8765   bot   → bot.app
            │
      конвейер service.pipeline — общий с контейнером, CLI и ботом
```

Оба exe лежат в одной папке и делят `_internal\` — Python 3.11, пакеты и
веса моделей (около 520 МБ). Вычисления в один поток, как в контейнере:
это условие побитовой воспроизводимости. Если WebView2 не запускается,
приложение открывает интерфейс в Edge, Chrome или Яндекс.Браузере в режиме
приложения (окно без адресной строки), а маленькое окно управления держит
сервис и завершает его.

Из исходников на любой ОС (Linux, macOS — окно или браузер):

```bash
pip install -r requirements.lock pywebview
python -m desktop                 # окно
python -m desktop serve           # веб-сервер для локальной сети
```

## Сборка установщика

Нужны [uv](https://docs.astral.sh/uv/) и [Inno Setup 6](https://jrsoftware.org/isdl.php)
(можно без прав администратора: `innosetup-6.x.exe /CURRENTUSER`).

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build_windows.ps1
```

Скрипт создаёт окружение Python 3.11 из `requirements.lock` и
`desktop\requirements-desktop.txt`, собирает PyInstaller по
`desktop\dxa_qc.spec`, проверяет сборку (версия, загрузка моделей, отчёт на
`demo.zip`, если он есть), кладёт в установщик инструкции из `docs\*.pdf` и
пишет в `dist\`:

- `DXA-QC-Setup-1.0.0.exe` — установщик (около 290 МБ);
- `DXA-QC-1.0.0-portable.zip` — та же программа без установки;
- `DXA-QC\` — распакованная сборка.

Сборка с нуля — около 5 минут, из них половина — сжатие установщика.
Иконка рисуется скриптом `desktop\make_icons.py`.

## Ограничения

- Только Windows x64. На Linux и macOS — контейнер или `python -m desktop`.
- Установщик не подписан: SmartScreen предупреждает при первом запуске.
- Модель ключевых точек (флаг `--keypoints`) в установщик не входит: ей нужен
  torch, это ещё 2 ГБ. Она и в контейнере по умолчанию выключена.
