## 2. Убрать PR-AUC из метрик

**Основание.** ТЗ, п. 8.4: «ROC AUC **и/или** PR AUC для бинарной
классификации»; приоритетные метрики — «F1-мера и ROC-AUC». PR-AUC ТЗ не
требует: ROC-AUC закрывает этот пункт.
