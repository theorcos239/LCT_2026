# Приложение на этом компьютере

Если снимки нельзя отправлять на сервер, откройте приложение локально. Оно
работает в браузере, но адрес `127.0.0.1` доступен только с этого компьютера.
Снимки загружаются в запущенный здесь же сервис и никуда наружу не уходят.

## Запуск на Mac

1. Убедитесь, что в `runs/keypoints_crops/` лежат лучшие веса `fold0.pt` и
   остальные имеющиеся `foldN.pt`. Файлы `foldN_last.pt` для просмотра не нужны.
2. Дважды щёлкните `tools/launch_local_app.command`. Либо выполните в терминале
   `sh tools/launch_local_app.command` из папки проекта.
3. При первом запуске скрипт установит недостающие библиотеки. Для этого один
   раз нужен интернет и программа `uv`. Последующие запуски и сам анализ могут
   работать без интернета.
4. Откроется `http://127.0.0.1:8000/`. Загрузите папку с DICOM, архив zip или
   отдельные снимки. Остановить сервис можно клавишами Ctrl+C в терминале.

Верхняя строка страницы показывает, загрузилась ли модель точек. Если нет,
страница прямо пишет об этом и продолжает анализ по доступным методам.

Модель точек сейчас помогает проверить покрытие Th12 и сверить оценку оси.
Согласование точек из нескольких кропов остаётся исследовательским режимом:
его проверка качества ещё не завершена, поэтому локальный запуск не включает
его автоматически. Оценку оси моделью точек также не подставляют вместо
контурной, пока не пройден отдельный контроль качества.

## Остальные варианты

Обычный `./run.sh` запускает лёгкий контейнер **без модели точек**. Он удобен,
когда нужны только методы, уже входящие в поставку. Windows-установщик также
собран без PyTorch и весов точек. Для локального приложения с точками на Mac
используйте команду выше; на другом компьютере можно установить зависимости
из `requirements.lock` и PyTorch, положить веса в `runs/keypoints_crops/`,
задать `DXA_QC_KEYPOINTS=1` и запустить `uvicorn service.api:app --host 127.0.0.1`.

По умолчанию отступы бедра проверяются по рисунку 6 ТЗ. Прежнее правило длины
поля можно выбрать через `DXA_QC_ROI_RULE=scan_length` перед запуском.

Числа качества, полученные на обучающих снимках, не являются результатом
проверки на новых пациентах. Разбор проверки модели точек и её ограничений —
в [SEMANTIC_CROP_CONSENSUS.md](SEMANTIC_CROP_CONSENSUS.md).
