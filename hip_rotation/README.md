# Ротация проксимального отдела бедра: `hip_rotation`

Проверка критерия ТЗ (п. 2.3, бедро): *«отсутствие ротации исследуемой области
(оценка малого вертела)»*.

> **В сервисе этот модуль — измерение, а не весь вердикт.** С 2026-09-28
> вердикт по ротации выносит свод выхода за коридор нормы с вероятностью
> сверточной сети [`cnn_qc`](../cnn_qc/README.md): OOF ROC-AUC 0.82 против
> 0.68 у одного выступа, вложенный F1 0.55 против 0.48. Выступ и коридор
> по-прежнему идут в отчёт и в карточку снимка, их вероятность —
> `thresholds.json` → `probability` (Платт, `python -m hip_rotation.calibrate`).

## Критерий двусторонний

По рис. 5 ТЗ нарушением считается и слишком маленький выступ, и слишком
большой:

| | что видно | |
|---|---|---|
| корректно | контур слегка деформирован малым вертелом | норма |
| переротация | контур плавный, малого вертела не видно | нарушение |
| недоротация | малый вертел слишком большой | нарушение |

Поэтому вердикт ставится не порогом «больше/меньше», а выходом измерения за
**коридор нормы** 96–272 мм², калиброванный по 15-му и 85-му перцентилям
кадров, признанных экспертом корректными.

## Использование

```python
from hip_rotation import detect, THRESHOLDS
res = detect(pixel_array, side='lh', thr=THRESHOLDS)
res['area_mm2']            # 131.7  — площадь выступа
res['bulge_mm']            # 13.3   — высота выступа
res['violated']            # True / False / None
res['text']                # 'переротация: малый вертел почти не выступает (...)'
res['confidence']          # всегда 'low' — см. ниже
```

```bash
python -m hip_rotation.calibrate      # коридор нормы + OOF-метрики
```

Сторона (`lh`/`rh`) приходит от `region_clf`. Верхушка большого вертела `T`
берётся из `hip_roi/kit2`, если не передана: оба критерия бедра опираются на
**один и тот же** ориентир, а не на два независимых.

## Как считается

1. Маска кости, сторона нормализуется (латераль слева).
2. Опорная прямая по медиальному контуру диафиза: Тейла-Сен по нижним 55 мм
   строк с костью, но не выше `T + 55 мм` — выше начинается вертельная зона.
3. Идём вверх от диафиза и **останавливаемся на входе в шейку** — там, где
   отклонение контура превышает 14 мм.
4. Выступ = отклонение контура от прямой в этом окне; в вердикт идёт площадь
   под ним, в мм².

**Остановка на шейке обязательна.** Без неё максимум отклонения приходится на
медиальный край шейки бедра, измерение даёт 60–70 мм вместо 3–8 мм и к малому
вертелу отношения не имеет. Это проверено: AUC при этом 0.63 при бессмысленных
абсолютных значениях.

## Результаты и почему они такие

Out-of-fold (5 фолдов, группировка по исследованию), 148 измеренных кадров
бедра из 153, 35 нарушений:

| | значение |
|---|---|
| чувствительность | 0.63 [0.46–0.77] |
| специфичность | 0.70 [0.61–0.78] |
| F1 | 0.48 [0.31–0.63] |
| ROC-AUC | 0.69 [0.56–0.81] |

**Это самый слабый критерий в решении, и причина известна заранее.** Разрыв
между классами по выступу малого вертела около 2 мм при ширине диафиза 35 мм
(см. [TODO.md](../TODO.md)), а выступ — разность двух координат, то есть ошибки
складываются. Чтобы уверенно различать классы, обе точки нужно находить
**точнее пикселя**. Контурная геометрия этого не даёт: 0.69 против 0.79–0.82 у
критериев позвоночника.

Поэтому `confidence` всегда `low`: разделяющая способность измерена, и обещать
большего нельзя. Точный путь — модель ключевых точек `src/dxa_qc`, которая под
эту задачу и проектировалась.

### Что проверено и не сработало

- **Модель по виду кадра** (та же, что сверяет критерии позвоночника): OOF AUC
  **0.50**, то есть сигнала нет вообще. Выступ малого вертела — слишком мелкая
  деталь для уменьшенного кадра, при 64–128 px она исчезает. Сверка для этого
  критерия поэтому не используется.
- **Выбор перцентиля коридора** по OOF: 5% → F1 0.47, 10% → 0.44, **15% →
  0.48**, 20% → 0.43, 25% → 0.37. Разница в пределах шума, взят максимум.

## Ограничения

- Переротированное бедро не имеет малого вертела по определению, и отличить
  «выступа нет из-за ротации» от «выступ не найден из-за маски» измерение не
  может — на это указывают флаги `rotation:neck_not_reached`,
  `rotation:short_window`.
- 5 кадров из 153 не измеряются (короткий кадр, не прослеживается медиальный
  контур) — вердикт `None`, флаг в отчёте.
- Коридор откалиброван на 113 корректных кадрах одного аппарата.
- Эндопротезы эксперт не оценивал, поэтому проверить на них нечем.
