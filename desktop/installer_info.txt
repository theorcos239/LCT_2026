КОНТРОЛЬ КАЧЕСТВА DXA — настольное приложение

Проверяет денситометрические исследования (DXA) поясничного отдела
позвоночника и проксимального отдела бедра по критериям ТЗ: укладка, ось,
посторонние предметы, ротация бедра, отступы области интереса. Работает
полностью на этом компьютере, без интернета: сервер поднимается внутри
программы и извне не виден, снимки никуда не отправляются, обновления сами
не скачиваются. Новую версию ставят этим же установщиком поверх старой —
отметки специалиста и токен бота при этом сохраняются.

ЧТО УСТАНАВЛИВАЕТСЯ
  «Контроль качества DXA»  — окно приложения: перетащите папку, zip или
                              DICOM-файлы, листайте снимки с разметкой,
                              скачайте таблицу отчёта, DICOM SR, визуализацию.
  «Командная строка (пакетная обработка)» — обработка большой папки без окна:
                              dxa-qc-cli batch D:\исследования --out report.xlsx
  «Веб-сервер для локальной сети» — тот же интерфейс в браузере для коллег
                              в вашей сети: dxa-qc-cli serve (порт 8000).
  «Telegram-бот»            — необязательный бонус, а не часть программы:
                              демонстрация интерфейса в мессенджере, тот же
                              анализ отвечает в чате, с телефона. Только
                              обезличенные данные. При первом запуске
                              попросит токен от @BotFather.
  «Инструкция — …»          — инструкции пользователя в PDF: приложение и
                              Telegram-бот.

ТРЕБОВАНИЯ
  Хватает обычного офисного компьютера или ноутбука.
  Система:    Windows 10 или 11 (64 бита), права администратора не нужны.
  Процессор:  любой 64-разрядный (x86-64) с двумя ядрами и больше.
  Память:     4 ГБ; сама программа занимает до 0.8 ГБ.
  Диск:       1 ГБ свободного места; программа занимает около 520 МБ.
  Видеокарта и интернет не нужны (интернет нужен только Telegram-боту).
  Окно приложения использует WebView2 Runtime — он есть в Windows 11 и в
  обновлённой Windows 10; без него интерфейс откроется в браузере.

  Программа не подписана сертификатом разработчика, поэтому Windows может
  показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

ВАЖНО
  Сервис — поддержка решения, а не медицинское изделие: окончательное решение
  о качестве исследования принимает специалист. Telegram-бот передаёт файлы
  через серверы Telegram, поэтому для реальных данных пациентов он не
  предназначен — используйте его только с обезличенными снимками.

Исходный код, руководства и метрики: https://github.com/theorcos239/LCT_2026
