# Установщик для Windows

**[DXA-QC-Setup-1.0.0.exe](https://github.com/theorcos239/LCT_2026/raw/master/release/DXA-QC-Setup-1.0.0.exe)**
— настольное приложение «Контроль качества DXA», 289 МБ.

| | |
|---|---|
| версия | 1.0.0, собрана из коммита `f45d34e` (29.09.2026) командой `desktop\build_windows.ps1`; установленная программа показывает коммит командой `dxa-qc-cli version` |
| система | Windows 10 или 11, 64 бита; 4 ГБ памяти, около 1 ГБ на диске |
| права | администратор не нужен: ставится в `%LOCALAPPDATA%\Programs\DXA-QC` |
| интернет | не нужен: приложение работает полностью локально (интернет нужен только Telegram-боту) |
| обновление | новый установщик поверх старого; отметки специалиста и токен бота сохраняются |
| SHA-256 | `6989bd30c2d5e8e509e1b4b21fd018d0da63f1d9010e9fd585eabfb592bf2bfa` |

Внутри тот же конвейер, веса и версии пакетов, что в Docker-образе: отчёт
совпадает с контейнером побитово (сверено на всех 252 снимках обучающего
набора).

Установщик не подписан сертификатом, поэтому Windows покажет SmartScreen:
«Подробнее» → «Выполнить в любом случае». Проверить, что файл не повреждён:

```powershell
Get-FileHash .\DXA-QC-Setup-1.0.0.exe -Algorithm SHA256
```

Что появляется после установки и как пользоваться — [инструкция пользователя](../docs/manuals/Инструкция_приложение.pdf) (она же ставится в меню «Пуск») и [docs/DESKTOP.md](../docs/DESKTOP.md).

Файл хранится через Git LFS (GitHub не принимает в git файлы больше 100 МБ),
поэтому `git clone` его не скачивает — ссылка выше или кнопка «Download» на
странице файла. Из клона репозитория:

```bash
git lfs pull --include="release/*"
```
